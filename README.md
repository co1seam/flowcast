# Flowcast

Documentaion: [docs](./docs)

## About the project

Flowcast is a pet project of a VOD streaming service for short clips. It's meant for videos up to 3 minutes and 720p: you upload them, they get transcoded for adaptive streaming, and you can see how many people watched what.

It's not a platform for everyone. It's a small thing I'm building to figure out how streaming pipelines and viewing analytics fit together. Uniformity of experience and simplicity are more interesting to me here than performance at scale.

## Status

Flowcast is in the documentation stage. There's no code to run yet — just the idea and the shape of the system being written down.
